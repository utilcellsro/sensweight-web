# unifiedcloudsensors.com

**Current state: a minimal static placeholder, not the real site.**

`index.html` is a single self-contained holding page — logo, one-paragraph company description, and a link out to [sensweight.com](../sensweight/) for actual product/industry content. No build step: open `index.html` directly, or deploy the folder as-is to S3/CloudFront. Deliberately plain (dark, serif, no design system) so it doesn't front-run whatever the real DNA turns out to be — treat it as fully disposable once real design work starts.

This will eventually be a small, minimal/premium corporate "about us" page for Unified Cloud Sensors, s.r.o. — safe to link from LinkedIn, distinct from the industry/product sales content on sensweight.com. It gets its own design DNA, separate from sensweight's (source: `../references/UCS-Web-DNA.html`, which belongs to sensweight instead) — **not yet sourced**.

Scope, once real design work starts: company info, minimal/premium tone, no ROI calculator, no demo, no per-industry content. Likely English-only as well, to be confirmed. At that point this will probably move to an Eleventy project matching `sensweight/`'s structure rather than staying static HTML.
