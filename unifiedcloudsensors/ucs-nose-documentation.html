1. Přehled

Software přijímá měření z jednotek „elektronického nosu“ UCS-Nose, vyhodnocuje kvalitu ovzduší a přítomnost látek a výsledky zpřístupňuje uživatelům ve webovém rozhraní. Měřicí jednotky komunikují se serverem přes mobilní síť 5G. Systém je vyvinut v projektu výzkumu a vývoje řešeném společností Utilcell, s.r.o. ve spolupráci s VUT v Brně.

3. Komunikace přes 5G

  • Jednotka je připojena k mobilní síti 5G a odesílá měření jako zprávy MQTT na broker.
  • Spojení je šifrované (TLS); každá jednotka se prokazuje vlastním klientským certifikátem, broker ověřuje certifikáty proti certifikační autoritě systému.
  • Zpráva nese identifikátor jednotky, časové razítko a hodnoty jednotlivých senzorů.
  • Vyhodnocovací proces a webová aplikace si data předávají přes REST API, takže každou část lze provozovat na jiném serveru.

4. Zpracování a vyhodnocení

Vyhodnocovací proces běží pro každou měřicí jednotku v nekonečné smyčce. Při každém kroku:

  1. na pozadí načte aktuální nastavení vyhodnocení (limity, režim strojového učení);
  2. získá nová měření jednotky;
  3. data validuje proti platnému rozsahu každé veličiny a sloučí měření senzorů do časových oken;
  4. vyhodnotí každou veličinu proti pásmům normální / zvýšená / nebezpečná, prahu alarmu a době trvání mimo normál;
  5. podle režimu (trénování / vyhodnocení / vypnuto) zavolá detektor anomálií a klasifikátor látek;
  6. výsledky průběžně a v pořadí odešle do webové aplikace, která je uloží a zobrazí.

5. Konfigurace vyhodnocení

Limity jsou uloženy v konfiguraci analysis_settings.json a lze je měnit z rozhraní. Příklad pro formaldehyd:

"fmhd": {
  "units": "ppb",
  "validInterval":     [0, 5000],
  "normalInterval":    [[0, 50]],
  "elevatedInterval":  [[50, 100]],
  "hazardousInterval": [[100, 300]],
  "criticalDurationSec": 3600,
  "alarmThreshold": 300,
  "domesticLimit":     { "min": null, "max": 50 },
  "occupationalLimit": { "min": null, "max": 300 }
}
KlíčVýznam
validIntervalFyzikálně platný rozsah; hodnoty mimo něj se vyřadí.
normal / elevated / hazardousIntervalPásma pro hodnocení stavu (může jich být více, např. příliš nízká i vysoká teplota).
criticalDurationSecJak dlouho smí být hodnota mimo normál, než se stav vyhodnotí jako kritický.
alarmThresholdHodnota, při které se okamžitě vyvolá upozornění.
domestic / occupationalLimitLimity pro domácí a pracovní prostředí.

Vyhodnocované veličiny: VOC index, formaldehyd, CO₂, CO, NO₂, O₃, NH₃, prachové částice PM1, PM2,5, PM4, PM10 a hmotnostní koncentrace, teplota a relativní vlhkost.

8. Typické postupy

Zapojení nové jednotky

  1. V části Moje senzory zaregistrujte jednotku jejím identifikátorem.
  2. Nahrajte do jednotky certifikát a připojte ji k síti 5G; první měření se objeví v Výsledcích senzoru.

Naučení nové látky

  1. V části Sběr dat spusťte sběr, zatímco je jednotka vystavena látce.
  2. V části Trénování látek natrénujte model a případně jej dolaďte.
  3. Přepněte jednotku do režimu vyhodnocení; rozpoznání látky se zobrazí ve výsledcích a upozorněních.

9. Instalace a spuštění

Vyhodnocovací proces

conda env create -f conda_environment.yaml
conda activate ucsnose_dataeval
pip install -e .
sensoreval run --box-id <identifikátor jednotky>

Adresa API webové aplikace (API_BASE_URL), identifikátor jednotky (BOX_ID), úroveň logování a adresář s modely se zadávají v souboru system_settings.env. Testy: pytest -m test_settings (jednotkové), pytest -m test_api_client_virtual (integrační).

Webová aplikace

Dodává se jako kontejner Docker (Python 3.12, Django 5); naslouchá na portu 8000. Databáze se volí proměnnou DB_ENGINE (mysql, jinak SQLite pro vývoj); výchozí skupiny uživatelů vytvoří příkaz initialize_user_groups.

Zdrojové kódy jsou vedeny v interním repozitáři; na vyžádání je poskytneme. Kontakt: info@unifiedcloudsensors.com.

10. Bezpečnost

  • Komunikace jednotek je šifrovaná (TLS) a každá jednotka má vlastní certifikát, který lze samostatně zneplatnit.
  • Webové rozhraní je dostupné jen přihlášeným uživatelům; oprávnění se řídí skupinami.
