Vyhodnocovací software s uživatelským rozhraním a podporou komunikace přes 5G síť

Software (výsledek typu R) · Technická dokumentace · English summary

UCS-Nose je „elektronický nos“: síť měřicích jednotek s plynovými a prachovými senzory, které průběžně sledují kvalitu ovzduší a přítomnost látek ve vzduchu. Výsledkem projektu je vyhodnocovací software, který data z jednotek přijímá přes mobilní síť 5G, vyhodnocuje je proti limitům a modelům strojového učení a výsledky zobrazuje ve webovém uživatelském rozhraní.

Jak systém funguje

Hlavní funkce

  • Příjem dat přes 5G. Měřicí jednotky komunikují se serverem přes mobilní síť 5G protokolem MQTT se šifrováním TLS a certifikátem pro každé zařízení.
  • Zpracování a validace. Měření z více senzorů jednotky se slučují do časových oken, neplatné a mimorozsahové hodnoty se vyřazují.
  • Vyhodnocení proti limitům. Každá veličina má platný rozsah a pásma normální / zvýšená / nebezpečná, prahovou hodnotu pro alarm a limity pro domácí a pracovní prostředí. Hlídá se i doba, po kterou je hodnota mimo normál.
  • Strojové učení. Detektor anomálií (hustý autoenkodér, práh na 98. percentilu chyby rekonstrukce) odhalí neobvyklé složení vzduchu; klasifikátor (logistická regrese) rozpozná naučené látky. Modely lze z rozhraní trénovat a doladit na konkrétní jednotce.
  • Výsledky a upozornění. Výsledky vyhodnocení se ukládají a zobrazují v rozhraní; překročení limitů vyvolá upozornění.

English summary

Evaluation software with a user interface and 5G communication support is a result of the UCS-Nose research and development project (Utilcell, s.r.o. with Brno University of Technology). Sensor units with gas and particulate sensors send measurements over a 5G mobile network (MQTT over TLS). The software validates the data, evaluates it against configurable limits, detects anomalies with an autoencoder model, classifies trained substances and shows results and alerts in a web user interface, from which users also manage sensors and train models. The system runs as a closed installation; access, a demonstration or the source code are available on request. See the technical documentation.
