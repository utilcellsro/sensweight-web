Architecture

One company, two domains

unifiedcloudsensors.com carries the brand. sensweight.com carries the sale.

unifiedcloudsensors.com

Presentational

Minimal, premium “about us.” Company story, safe to link from LinkedIn. No calculator, no demo, no per-industry content.

sensweight.com

Solutions-based

Where the depth lives: Industries → Solutions → Products, the ROI calculator, and the live monitoring demo.

This split is an industry norm, not a new idea
Bosch → Bosch Sensortec Same industry as us: corporate shell vs. the sensor business's own product-depth site.
Alphabet → Google abc.xyz is pure shell; google.com is where every product and sale happens.
Danaher → Fluke Closest to our scale: parent site routes out, operating company's domain sells.
Launch order: sensweight.com ships first. The existing unifiedcloudsensors.com placeholder already links straight to it — real corporate-site design work starts only after sensweight.com is live.

Discoverability

Built to be found — by search engines and AI answer engines

Classic SEO gets us ranked. AIEO gets us cited — quoted directly inside AI answers.

SEO foundations

Phase 1
  • Titles + meta descriptions per page
  • sitemap.xml + robots.txt
  • Canonical tags
  • Open Graph + Twitter Card meta
  • Organization schema (JSON-LD)
  • Favicon — currently missing

AIEO / structured data

Phase 2
  • Product schema on all 5 Solution pages + UCS X3
  • BreadcrumbList schema — pairs with the breadcrumbs just shipped
  • FAQPage schema with real Q&A content
  • Quotable, self-contained opening definitions per page
Neither phase needs design changes — cheap, high-leverage, can start anytime. Currently not started.
